`.envrc` (generated by `~/Documents/Github/dotfiles/scripts/linker.sh forge/StagingOvercloud`) runs `use flake .` and then `use flake ~/Documents/Github/dotfiles/forge/StagingOvercloud/`. nix-direnv appends the earlier PATH, so both shells' tools are available.

- The repo flake (nixpkgs pinned to 2023-11) provides opentofu (1.6.0-alpha), vault, openstackclient and the pre-commit hooks, and sources `config.sh` (VAULT_ADDR, OS_CLOUD).
- The dotfiles flake (nixos-unstable) adds kubectl, kustomize, helm, k9s, kubectx, stern, argocd, ansible, jq, yq-go and glab.

**Why:** the repo flake is shared with the team and must not be changed for personal tooling.
**How to apply:** add personal tools to the dotfiles flake and never to the repo's `flake.nix`. The tofu version is old because of the repo's pin, so bump it in the repo flake only if the team agrees.
